# 편입영어 트레이너

Notion의 `편입 영어 오답노트`를 모바일에서 반복 학습하기 위한 개인용 PWA입니다.

기존 `bigdata-analysis-engineer-written`에서 검증한 학습 흐름을 재사용하되, 편입영어에 맞게 **보기 없는 회상 → 정답 확인 → 몰랐음/애매함/확실히 앎 평가 → 약점 우선 재출제** 구조로 바꿨습니다.

## 현재 데이터

- 어휘 40개
  - `2026-08-29 | 어휘 581~620 · 오답 5·9·11`
  - `2026-08-29 어휘 p.14~18 오답과 별표 정리`
- 문법 15개
  - `provide A with B`
  - `view A as B`
  - `allow A to V`
  - `recommend that S V원형`
  - `occur` 자동사, `join`·`visit` 타동사
  - `lie / lay` 구분
  - `participate in`, `get 목적어 to V` 등

## 학습 방식

### 오늘의 12개

매일 어휘 8개와 문법 4개를 고릅니다.

우선순위는 아래 순서로 높아집니다.

1. Notion에서 아직 최종 구분이 남은 혼동어
2. 실제 오답 또는 미선택 항목
3. 별표를 했거나 확신 없이 맞힌 항목
4. 앱에서 `몰랐음` 또는 `애매함`으로 기록한 항목
5. 아직 앱에서 학습하지 않은 항목
6. `확실히 앎`을 반복한 항목

같은 한국 날짜에는 처음 생성한 오늘의 세트를 유지합니다.

### 복습 간격

- 몰랐음: 1일 뒤
- 애매함: 1~3일 뒤
- 확실히 앎: 3일부터 시작하여 성공할수록 간격 증가
- 최대 간격: 30일

## 구조

```text
.
├── index.html
├── app.js
├── styles.css
├── manifest.webmanifest
├── sw.js
├── icon.svg
├── content/
│   ├── vocabulary.js
│   └── grammar.js
├── scripts/
│   └── validate-data.mjs
└── .github/workflows/
    └── validate.yml
```

앱 코드와 학습 데이터를 분리했습니다. 이후 Notion 자료를 추가할 때에는 주로 `content/`만 갱신하면 됩니다.

## 실행

정적 웹 서버에서 저장소 루트를 제공하면 됩니다.

예를 들어 Node.js가 있다면 다음처럼 실행할 수 있습니다.

```bash
npx serve .
```

데이터 검증은 다음 명령으로 실행합니다.

```bash
node scripts/validate-data.mjs
```

## 저장 방식

학습 기록은 브라우저의 `localStorage`에 저장합니다.

앱 안에서 JSON 백업과 복원을 지원하므로 기기를 바꾸거나 브라우저 데이터를 초기화하기 전에 백업할 수 있습니다.

## 배포 주의

이 저장소에는 개인 학습용으로 정리한 교재 기반 자료가 포함될 수 있습니다. 저장소를 공개로 전환하거나 정적 사이트를 공개 배포하기 전에 저작권이 있는 교재 원문과 문제의 공개 여부를 반드시 다시 검토합니다.

현재 저장소가 private이더라도 GitHub Pages 등으로 배포한 사이트의 접근 범위는 별도로 확인해야 합니다.
